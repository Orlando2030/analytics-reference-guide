## 📂 Estrutura do Repositório

### 1. Fundamentos (/1_fundamentos/)
*   **Programação Python:** Manipulação de dados e lógica.
*   **EDA:** Limpeza e estatística descritiva.
*   **Visualização:** Matplotlib e Seaborn.
*   **Estatística:** Fundamentos e probabilidade.

### 2. Machine Learning (/2_machine_learning_e_modelagem/)
*   **Modelagem:** Clustering, Regressões e Modelos Logísticos.

### 3. Análise Especializada (/3_analise_especializada/)
*   **Séries Temporais:** Tendências e sazonalidade.
